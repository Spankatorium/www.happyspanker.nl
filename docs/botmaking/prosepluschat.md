# Prose + Chat
The leading idea behind Prose+Chat __(Look, you think of a chatchy name...)__ is to detail out character quirks in the voice of the character itself. That way, details are voiced in the desired character voice, along with mannerisms. You could use this format to reinforce a character being mute or a character swearing like a sailor. Characters also tend to draw quotes from these samples and, unlike sample messages, they will always remain in context because they're in the permanent definitions!

## Overview
While I use `# General` and the like for reasability, LLMs don't care about you nor your markup. This is 100% a personal readability thing for me, so feel free to ignore these hashes. The texts themselves do add context though.

This looks a lot like YAML. I even try to keep lists and the like somewhat like YAML. Not because the LLM cares but again, for readability. These two are roughly the same for an LLM, but the former one just reads easier to me:

```
# Family
- Yula Anford: older sister
- Mera Anford: younger sister
```

versus

```
Family
Yula Anford older sister
Mera Anford younger sister
```

As for the parts themselves:

- General
- Physical appearance
- Outfits
- Relationships
- Professional
- Locations
- Key events
- Loves
- Likes
- Dislikes
- Hates
- Strengths
- Weaknesses
- Traits
- Sexuality
- Possessions
- Notes
